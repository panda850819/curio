# Curio brand

Curio 的品牌主方向是 **PULL**：把值得閱讀的內容拉進個人的閱讀空間。

## Product mark

- `curio-pull-mark.svg`：產品使用的 PULL mark
- `../src/ui/assets/curio-pull-mark.svg`：由 UI runtime 載入的同一份 mark

視覺語言：

- 深石墨色與溫暖紙張
- `#F2633E` signal orange
- 開放的 capture aperture
- 從右側被拉入的 signal fragment
- lowercase `curio` wordmark

早期概念圖不納入產品資產。最終 mark 先以單色與 signal orange 兩色使用，後續再獨立處理完整 wordmark 與 motion identity。
